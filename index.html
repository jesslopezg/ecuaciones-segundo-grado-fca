Guía rápida

ax² + bx + c = 0

a es el coeficiente cuadrático, b el lineal y c el término independiente.

Fórmula general

x = (-b ± √(b² - 4ac)) / 2a

Discriminante

Δ = b² - 4ac
  • Δ > 0: dos soluciones reales.
  • Δ = 0: una solución real doble.
  • Δ < 0: no hay soluciones reales.
En negocios: una solución matemática puede no tener sentido si representa una cantidad negativa de productos, personas o dinero.
