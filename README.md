# Ecuaciones de Segundo Grado — FCA

Aplicación educativa para estudiantes de tronco común de la FCA.

## Contenidos
- Identificación de a, b y c
- Factorización
- Fórmula general
- Discriminante
- Problemas aplicados a negocios
- Práctica libre
- Reto de 10 ejercicios
- Modo examen
- Progreso guardado localmente

## Publicar con GitHub Pages
1. Ve a **Settings → Pages**.
2. En **Source**, selecciona **Deploy from a branch**.
3. Elige la rama **main**.
4. Selecciona **/(root)**.
5. Guarda.
